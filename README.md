# SingleTimesTables
Practice Game for Times Tables

A quick HTML/CSS/Javascript game I made for my kids to practice their times tables.

It's configurable to how many questions, time limit, times tables and how high to run the tables. It will flag wrong answers and the final report shows how many wrong answers were clicked.

All the code is embedded in a single html file for simplicity.

It can run out of github pages, or download the index.html to run locally.
